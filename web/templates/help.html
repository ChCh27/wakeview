Help

Cost (API est.)

Claude Code writes cost-state records into the session file with running totals: cost, tokens per model, time and lines changed. wakeview shows those totals. They include subagents and background calls such as title generation.

The cost is Claude Code's own estimate at API prices. On a Pro or Max subscription you are not billed this amount.

Each Claude Code process counts from zero, so a session continued with --resume has several sets of totals; wakeview adds them up. A session with no cost-state records shows "—".

Duration and API time

Duration is how long Claude Code ran for the session, including the time it waited for you. API time is the part spent waiting for the model to respond.

Tokens: Input and Output are tokens sent and generated; Cache read and Cache write are prompt-cache tokens read and stored.

Messages

The count of your prompts and Claude's text replies. Tool calls and thinking are not counted.

Directory missing

The name of a project directory under ~/.claude/projects can't be turned back into a path reliably, so wakeview takes the path from the cwd field of the session records and checks that it exists on disk. When it doesn't, the project is marked directory missing. Its sessions are still readable.

Instructions

The CLAUDE.md files Claude Code loads into a session, in load order:

  • global: ~/.claude/CLAUDE.md and ~/.claude/rules/*.md, for every project;
  • parent: CLAUDE.md and CLAUDE.local.md in the directories above the project;
  • project: CLAUDE.md, .claude/CLAUDE.md and .claude/rules/*.md in the project;
  • local: CLAUDE.local.md in the project.

Git marks: tracked files are committed and everyone who clones the repository gets them; tracked · modified have uncommitted changes; untracked files are in a repository but not in git, so only you have them. No mark means the file is outside any repository. @path imports and CLAUDE.md files in subdirectories are not shown.

Search

Case-insensitive; all words must occur in the same message. Prompts, replies and memory are searched; tick include tool calls to also search tool inputs and results. Thinking and subagent transcripts are not searched. Right after wakeview starts, the first search can take a couple of seconds while it reads the sessions.

Live updates

An open session page shows new messages as Claude Code writes them. When you are at the bottom of the page, it scrolls to follow them.

Rename

wakeview appends the same custom-title record Claude Code writes for /rename, so /resume shows the new name too. The rest of the file is not changed.

Trash

Deleting a session moves its transcript, its <id>/ directory (subagents, large tool results), file-history/<id> and session-env/<id> to ~/.claude/wakeview-trash/. Deleting a project moves its whole directory under ~/.claude/projects and every session's file-history and session-env. The project's working directory is never touched.

Restore moves everything back; it refuses when something already exists at the original place, for example when Claude Code has created the project directory again. Delete forever removes the files for good.

A session changed less than 5 minutes ago may still be running, and Claude Code would write it again, so it can't be renamed or deleted until then. The same applies to a project with such a session.
